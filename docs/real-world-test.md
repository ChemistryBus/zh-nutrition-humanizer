# 真实稿测试：一份 2 万字的减脂报告

> 用作者本人的真实稿件做 held-out 测试，不把原文放进仓库。
> 材料：`科学减脂洞察与专家指导1106.docx`（156 段、20 348 字，无表格）。

## 这份稿子测什么

它不是 AI 生成的负样本，而是**已经在往机构语体上改的真人稿**。这类稿子的语体命中率本来就低
（1.7 处/千字），正好用来测另一件事：**术语层能不能抓到人眼容易漏的错**。

改动前的工具只报 33 处语体命中，术语层 0 处——不是稿子没问题，是术语表只覆盖 22 个词。

## 加入术语层之后

| 层 | 命中 | 例子 |
|---|---:|---|
| K2 首选术语 | 3 | `中心性肥胖`×2 → `中心型肥胖`；`β氧化`×1 → `β-氧化` |
| S4 缩写首现 | 5 | `AMPK`、`IGF-1`、`GLP-1`、`DPP-4`、`BMI` 首次出现未给中文全称 |
| S5 汉字单位 | 4 | `公斤`×1、`克`×1、`千卡`×2 → `kg`、`g`、`kcal` |
| C2 破折号区间 | 16 | `60%—70%`、`0.5—1公斤`、`7—9小时`、`5%—10%` |
| C1 「至」区间 | 9 | `6至8个月`、`2至3次` |
| S2 术语混用 | 1 | 能量×49 / 热量×19 |

合计 **49 处**，其中术语层 12 处（K2 3 + S4 5 + S5 4）。

**为什么这些是错，不是风格偏好**

- `中心型肥胖`：三份政策文件（体重管理指导原则 2024、成人肥胖食养指南 2024、居民体重管理核心知识 2024）
  全用「中心型」；《中国成人体重管理指南（2025）》用「中心性」。按稿件定位（面向公众的指导报告），
  取政策写法，并保持全篇一致。
- `β-氧化`：连字符是术语的一部分，去掉就成了另一个词形。
- `公斤/克/千卡`：《成人肥胖食养指南（2024年版）》公斤 0 次、kg 23 次；千卡 0 次、kcal 189 次。
- 缩写首现：指南写「内脏脂肪面积（VFA）」「基础代谢率（BMR）」；稿子里 `VFA`、`BMR` 展开了，
  `AMPK`、`IGF-1`、`GLP-1`、`DPP-4`、`BMI` 没有——同一个毛病，稿内自相矛盾。

## 机械润色之后

`polish.py` 干跑报 30 处确定性改动：β氧化、破折号区间、汉字单位全部自动改掉。

再跑术语层，剩 7 处：

| 剩余 | 为什么机器不改 |
|---|---|
| `AMPK`、`IGF-1`、`GLP-1`、`DPP-4`、`BMI` 各 1 | 补中文全称要判断语境，改错比不改更糟 |
| `中心性肥胖`×2 | 政策/期刊两种写法都有，是取舍不是对错 |
| 能量 / 热量混用 | 要逐句判断哪个词在指「能量」、哪个在指「食物热量」 |

## 结论

- 术语层把「看得见的错」从 0 提到 12 处：5 处（β氧化 1 + 汉字单位 4）可自动改，7 处（缩写 5 + 中心性 2）给出定位和依据、留给人。
- 真实稿的语体问题少（1.7 处/千字），术语问题多（0.6 处/千字）——两类问题不是一回事，
  工具必须分开报。
- 这份稿子的性质决定了它适合当「真人稿」样本，不适合当负样本；负样本仍用 `eval/neg/`。
