# 盲评包

两轮盲评的原始材料。任何人可以用同一份包重做一次真人盲评。

## 文件

| 文件 | 说明 |
|---|---|
| `packet.md` | 第二轮盲评包：20 组，每组 A/B 两段，顺序随机且 10:10 对调 |
| `key.csv` | 第二轮答案键：每组 A、B 分别是改前还是改后 |
| `scores_round2_C.csv` / `scores_round2_D.csv` | 第二轮两位评分者的 1–5 分 |
| `packet_round1.md` / `key_round1.csv` | 第一轮盲评包（教材体条目未修订） |
| `scores_round1_A.csv` / `scores_round1_B.csv` | 第一轮两位评分者的分数 |

## 评分口径

只回答一个问题：**这段文字像不像中国营养学会教材或国家卫健委食养指南**，1–5 分。

| 分 | 判断 |
|---|---|
| 5 | 可以直接进教材／指南，看不出机器痕迹 |
| 4 | 基本是机构语体，个别句子偏软 |
| 3 | 能读，但明显是科普号手笔 |
| 2 | 口语化明显，术语或单位不规范 |
| 1 | 营销腔／网文体，不能用于书稿 |

## 怎么自己跑一遍

1. 打印 `packet.md`，遮住 `key.csv`。
2. 找 2–3 位没参与改写的人，各自独立打分，不要讨论。
3. 按 `key.csv` 还原改前／改后，算配对差值与胜负。
4. 把新分数放进本目录（`scores_roundN_X.csv`），并在 `eval/results.md` §6 记账。

## 需要说明的两点

- **第一轮的教训**：教材体条目被压成电报句，两位评分者都把「改后」判负（18 次里 0 胜）。
  修订后才进入第二轮。这条经验写进了 `SKILL.md`「已知局限」。
- **引号体例**：`packet.md` 在评分后统一改成了大陆标准引号 `“”`（原为 `「」`）。
  评分者 C 曾因此扣分，所以现在这份包的分数只会偏保守，不会偏乐观。
